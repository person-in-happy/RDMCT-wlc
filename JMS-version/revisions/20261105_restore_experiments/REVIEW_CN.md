# 实验恢复与命令整理记录（2026-11-05）

## 修改原因

11月3日的 `../20261103_results_default_residency/REVIEW_CN.md` 记录了默认参数变更：非递减出片、工艺腔非加工驻留100s、机械手100s、时域10000s。旧协议使用10000s总驻留、100000s时域，不能直接支持新默认参数下的成功率、运行时间或方法排名。此前据此把旧比较整体撤出正文，只保留可重新验证的排程见证，导致引言仍承诺表示和节拍消融，而实验章节缺少相应内容。

本次恢复有原始协议、完整对照和验证记录的机制实验，并明确标注实际参数。没有把旧实验改写成100s实验，没有选择性删除同一对照组的不利结果，没有补跑求解器。

## 证据复核

`collect_evidence.py` 在独立进程中分别加载旧协议与当前协议的物理验证器，从保存事件重新计算等待、节拍和产品完工时间，不导入求解器或构建MILP。保存原始模型检查证书、输入/输出哈希检查结果、冻结代码核对及逐单元路径。

- 扩展窗口106份结果全部通过新的独立物理重放；已有结果、配对输入和冻结资产哈希核对无差异。
- 24份普通精修与6份资格精修的第一阶段和第二阶段都通过重放；产品完工变化最大约1e-6s，全部30对总等待下降。
- 搜索策略及节拍权重的每个实例/种子内输入赋值哈希相同。
- 100s小实例获得5份有效解，其中4份主问题最优；较大混合实例3份有效解；选割完整比较9份有效解。其余均保留原始停止状态。
- 当前216次模式扫描全部结束，192次timelimit、24次memlimit，均无可行解；不推断不可行或模式排序。
- 没有重新执行完整MILP赋值检查；本次核对保存的原始模型检查证书，并重新独立验证物理排程。文稿未把本次复核写成新一轮求解。

逐单元证据见 `extended_evidence.json` 和 `current_evidence.json`。重复种子先按实例汇总；没有统计显著性声明，也没有将同一排程的多个文件重复计作独立实例。

## 关键修正

- 不能沿用旧文稿中更早FIFO批次的精修数字：本次表格使用后来非递减出片批次的阶段内配对重新计算。
- E与D不仅驻留上限/计时方式不同，复位尾段时域边界也不同：旧 `add_interval` 没有 `s <= H` / `e <= H`，当前模型有。已恢复E结果中6份最终精修排程的复位完成达到100018s；其原协议合法，但不能冒充当前模型仅放宽驻留的实验。正文实验设置已明确这项历史边界，未重写其事件或证书。
- 100s补跑的四个主问题最优值为296s、303s、324s、324s；另有混合双片518s可行解。第一阶段status与固定结构第二阶段status分别解释。
- 保留固定结构优于限时联合搜索的观测；不能用表示压缩直接推导更快求解。
- 节拍权重保留24片实例没有变化的结果，16片实例报告节拍下降8s且等待增加16s的真实折中。
- 选割保留完整覆盖摘要，不宣称其获得可行解概率或产品完工质量有优势；未按有利结果筛选种子。
- 以新的100s全量结果表替换较早六份物理见证的上界表，避免同时列出313/314/438/639s等已被改进的上界而引起混淆；原数据保留在备份和原审核目录。甘特图仍对应原已验证324s/342s排程，不与新的精修事件混用。
- 同步修改摘要和结论，避免正文已恢复实验而摘要仍声称只有六份排程。
