# 32片规模实验的内存失败诊断

日期：2026-10-31。

原批次：`JMS-version/results/pjob_fifo_scale32_all_20261031_174246`。

## 已确认原因

队列共有9项；6项完成并保存了通过原约束检查及独立物理重放的可行解，3项因 `process_memory_guard` 被强制终止。失败项均为 `n32_H3_2x2_dual`，种子1、2、3。

原进程RSS上限为14336 MiB（14 GiB），SCIP自身的内存限额为18944 MiB。两者统计口径不同：前者监测整个Python/SCIP进程，后者传给求解器。此次直接终止进程的是RSS保护器。三个失败进程的采样峰值分别为15348.74、14491.23、14365.25 MiB；采样间隔为1秒，因此峰值可以高于触发阈值。

三个失败实例均已完成模型构建，模型有1915753个变量、6689576条约束、39415754个线性非零系数，其中Pjob库存选择变量为256个。其余变量主要来自完整候选对、周期及物理资源约束。减少产品身份排列并未消除这些规模项。

三个 `warm_start_check.json` 均记录 `accepted=true`，求解日志记录初始上界9956 s；但没有保存完整的 `phase1.json`、`result.json`、`evidence.json`，因此不能把这三项记为已完成观察。这是执行失败，不是不可行证明。
