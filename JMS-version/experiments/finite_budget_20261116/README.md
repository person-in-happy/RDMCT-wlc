## 预先固定的协议

### A. 联合目标与两阶段：60次

四个共同初始排程：当前默认模型D下2片混合（518 s）、4片混合（542 s）、16片纯4×1（920 s）；宽驻留模型E下16片纯2×2（2537 s，存在有效节拍中心）。输入一律使用预定种子1的保存排程，不根据新增算法结果选择。D与E各自使用原后端和原参数，分开报告。D下8片混合没有合格初始赋值，作为覆盖缺口保留。

每例3个求解种子、5臂：

- 仅批次完工时间：300 s。
- 两阶段：270 s最小化产品回片完工时间，30 s固定主要离散结构（同步选择除外），在保持主目标上界下精修。
- 联合加权目标：`Cmax/C0 + rho*F/F0`，`rho ∈ {0.01, 0.1, 1}`，各300 s。

`F = 总路线等待 + 10×最大单项等待 + 25×同链节拍偏差`；`C0`、`F0`由各例同一初始排程的实际事件计算，下限取1，并在运行前冻结。联合目标保留完整离散空间，不给予额外搜索时间。权重反映不同目标取舍，不将任意一个权重当作所有联合目标的代表。比较向量为批次完工、总/最大等待、节拍偏差、有效中心数与加权次目标；优劣应说明是完工优先排序、Pareto支配还是目标折中。零有效中心不能解释为节拍更稳定。

### B. 较大输入的组件消融：96次＋6次共享SPBS准备

固定使用D下4片混合与16片纯4×1。每例、每求解种子只做一次60 s非学习SPBS，各方法共享完全相同的赋值哈希，随后各有240 s主求解预算，关闭精修。准备只执行一次，但每臂计入60 s，不转移未用满时间。

比较SCIP、HEM、仅扩展特征、去结构重排、贪心替代束搜索、完整选割。SCIP每例3次；其余各3个冻结训练种子×3个求解种子，每例48次，两例96次。去结构重排及贪心变体共享完整方法的网络参数；仅扩展特征使用其独立冻结网络，属于组合变化。不得将96次重复写成96个独立实例，也不把16片甘特图本身当作算法优势证据。

总计162个队列单元，其中156次正式比较、6次共享准备；名义求解预算合计11.5小时，建模、策略加载和验解另计，可并行的独立任务缩短实际耗时。
