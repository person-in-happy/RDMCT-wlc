# 75 片混跑，完工时间间隙 1%，腔室空闲间隙 0.001%

输入沿用 D 场景的四个装载端口，共 37 片 4×1 和 38 片 2×2。第一阶段从原始混跑可行解重新搜索，以末片产品返回为完工时间。第二阶段以本次第一阶段的完工时间为上限，最小化从零时刻到实际末片返回期间 CH2 和 CH3 完全空闲的累计秒数。单腔空闲、腔内停留及设备占用结束时间也受本次第一阶段排程约束。

在仓库根目录的 PowerShell 中运行

```powershell
.\JMS-version\experiments\scale75_mixed_two_gaps_20261119\control.ps1 -Action Run
```

运行期间按 Ctrl+C 可中断。再次启动时使用 `-Action Resume`，程序会校验实验参数和已保存的结果，并从最近完成的分组层或邻域继续。`-Action Status` 可查看进度，`-Action Verify` 可复核已完成的结果。各阶段依次使用一个求解线程，进程提交内存上限为 1 GiB。系统可用内存低于 3 GiB 时，程序等待后再进入下一个求解步骤。

结果位于 `JMS-version/results/scale75_mixed_A1pct_B0p001pct_D_20261119/`。其中 `report.json` 汇总实测指标、回放检查和下界，`final/figures/` 保存总图和每页 600 秒的详图。第一阶段全模型证据采用工作负荷下界。第二阶段连续时间证书适用于最终的分组、腔室分配和资源顺序。两项设置都是相对求解间隙阈值。
