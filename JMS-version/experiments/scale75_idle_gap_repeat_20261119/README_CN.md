## 运行与核验

从仓库根目录的前台 PowerShell 执行。参数 `-GapPercent` 直接填写百分数，入口把它除以 100 后传给求解器。每轮独立使用单线程 CPU 和 1 GiB 的进程内存上限，各步骤完成后写断点。按 Ctrl+C 后以相同参数执行 `Resume` 可继续。要从头独立重复同一设置，可为各命令传入相同的新 `-Campaign` 结果目录。

```powershell
$entry = ".\JMS-version\experiments\scale75_idle_gap_repeat_20261119\control.ps1"
& $entry -Action Run -GapPercent 0.000000001
& $entry -Action Status -GapPercent 0.000000001
& $entry -Action Resume -GapPercent 0.000000001
& $entry -Action Verify -GapPercent 0.000000001
```

核验会从物理事件重建目标值和泳道，检查前次归档、新旧两版的排程与图件指纹、各次直接求解实际接收的间隙，以及固定顺序连续时间模型的上下界。对本次阈值的判定直接使用记录的上下界，不在 `1e-11` 上另加数值宽限。完整原模型的逐行核验覆盖所有候选配对与周期。
