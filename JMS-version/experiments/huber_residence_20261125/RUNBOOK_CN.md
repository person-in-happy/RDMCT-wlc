# Huber 驻留目标实验

运行 `./JMS-version/experiments/huber_residence_20261125/resume.ps1` 可在前台查看和恢复实验。结果保存在 `JMS-version/results/huber_residence_20261125`。目标把产品平均非加工驻留、同配方最大驻留极差的 Huber 罚项和实际提前清洁损失相加。Huber 转折点为 1 秒，每个提前清洁所损失的生产配额折合 1 秒。

固定排程结构上，若每种配方只对应一个产品对，极差在所有允许的重定时中恒为零。其余结构上，不论极差取何值，线性目标和 Huber 目标的差均在 0 到 0.5 秒之间。每个种子的原始可行见证在新目标下重新计分，与相应的新下界组合后计算相对间隙。自由目标的种子记录使用新见证、事件回放与全局下界。

表五保留同一种子的完整方法壁钟预算和同时达标规则。三个完整方法的交接结构都具有恒为零的极差，原生计时和目标可直接使用。对照臂的证据分别记录于 `runs/t5_*/A_reuse.json`。未获得足够候选解或严格目标差界证据的比较臂按相同预算重新运行。`table5_provenance.csv` 逐行给出来源。`progress.json` 给出实际已用时间、完成数以及基于配对限时和共享工期轨迹的动态预计剩余时间。

作业在中断后接管仍在运行的工作者，复核已经完成的端点，并从原生可行解、工期下界、选割轮数和三秒预算心跳重新开始未完成的搜索树。全部种子齐备后，`final_audit.py` 核验两张表和原始来源并写入 `final_audit.json`。
