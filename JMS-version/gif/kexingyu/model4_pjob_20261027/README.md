## 输入及读取标准

每个规模包含纯4×1/纯2×2与H=3/10的四个配置，双源、两腔CH2/CH3、8片辅助片，四个LP各放N/4片产品，时域100000秒。每个配置包含三个Pjob：

| 任务 | 来源库存 | 资格 |
|---|---|---|
| Pjob1 | LP1 | 仅CH2 |
| Pjob2 | LP2 | 仅CH3 |
| Pjob3 | LP3、LP4 | CH2、CH3均可 |

每个Pjob的模式等于该配置的纯配方。不同配方属于不同配置；本次没有把混合配方结果混入这些文件。除任务资格和腔室标识外，物理参数沿用模型2默认值。旧文件使用CH1/CH2且没有本任务资格限制，因此两者数量不作为同一可行空间的直接对比。

沿用模型2简化版格式：只显示晶圆、ATR/VTR取放和位置，按动作开始时刻排序；同刻动作使用`{动作A || 动作B}`。`->`表示开始次序，不一般性地表示前一动作已结束。本构造恰好采用串行块，不覆盖所有并行结构。旋转、加工/清洁曝光、结束边界和数值时间保存在完整证据中。

`LP2.1`对应产品`LP2_W1`，按25片LP区间编号规则就是26号；一般编号为`25*(LP-1)+槽位`。`PEC1`是实体辅助片D1，不是VTR手爪。腔室装卸一对晶圆仍显示为一个共同动作。

## 为什么计数不再依赖产品身份置换

优化层先选择长度为N的“来源LP、加工腔室”序列，随后按各LP的取片次序给具体产品赋号。LP1固定选CH2，LP2固定选CH3；LP3/LP4的每片产品各有两个腔室选择。同Pjob同LP产品编号不能自由排列产生新记录。

四类LP各出现N/4次，来源序列数为`N!/((N/4)!)^4`；其中N/2次灵活任务各有两个腔室选择，所以每个固定配置的构造族大小为：

`L(N) = N!/((N/4)!)^4 × 2^(N/2)`。

不同来源或加工腔室会改变实际取放序列，因此此映射在该构造族中是单射。模型2旧文件依靠任意产品身份排列得到的N!下界不直接用于这里。

两个配方各选文件条数的一半，在其构造编号范围内等距抽取；H=3和10的同一显示顺序合并并在标题注明。因此8片文件包含两个配方各20,160条，不是每个配置分别40,320条。

## 可行性和验证证据

每个产品单独完成满片工艺，辅助片补位；随后清洁并归还全部物料。4×1每块一次生产，2×2每块同腔连续两次生产，清洁后计数归零。块首按900秒间隔排列，覆盖块内结束时间、LL复位及最大移动保护间隔。最坏完整终点分别为7150、14350、28750秒，均小于100000秒。实际产品Cmax单独按最后产品回片计算，不能用含末端清洁的完整终点替代。

验证范围与模型2扩大版采用同一分层口径：

- 24种合法单块映射均执行完整物理重放。
- 150,320条输出逐条检查来源库存、腔室资格、规范化解码及不重复取放序列；块间可行性由固定保护间隔证明。
- 每个规模、配方、H的首/中/末构造编号执行完整规模重放，共36条配置见证。
- 六条阅读示例各对H=3、10重新验解，共12条附加完整见证。
- 专项测试检查身份置换不增加匿名排程、真实来源/腔室变化仍保留、错误资格与库存被拒绝。

没有对每条记录重新运行MILP，也没有证明这些串行排程最优。模型4完整MILP的求解性能比较尚未进行。构造器使用已冻结的模型2物理构造与验解组件，并新增Pjob库存、资格和匿名计数检查。
