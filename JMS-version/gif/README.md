# 加工逻辑动画

本目录的 GIF 是单腔室工艺逻辑示意，不是求解排程回放；播放时长不按真实时间缩放。

- `mode_4x1.gif`：两对产品、四片晶圆同步加工一次（名义 180 s），后装先卸。
- `mode_2x2.gif`：三对产品形成完整链，依次加工 D+P1、P1+P2、P2+P3、P3+D；每对产品连续参加两次曝光（名义 90 s/次）。
- P1/P2/P3 各表示两片产品；D 表示两片辅助晶圆，不计为产品。链首 D 卸出返回辅助存储后，可在链尾再次借用。辅助晶圆仅用于生产补位，这里没有执行清洁。
- 每次加工前四工位均满片；半周旋转交换前、后访问侧；装卸仅在前侧发生。换片分开展示卸出和装入以便理解，不表示模型禁止合并交换。
- 示例省略 LP、对准、装载锁、VTR 逐手分配及跨腔竞争；腔外区域是供回片的逻辑示意，不是实体设备布局或精确轨迹。
- 2×2 展示单段四周期链，假定清洁间隔允许该完整链，例如从零计数开始且 H≥5。需要清洁时不能打断同一产品的两次连续曝光。
- 4×1 展示满产品批次；产品不足时由辅助晶圆补足空位。

依据（本次只读核对）：

1. `../JMS_Review_CN.tex`：第 164–176 行模式说明及工艺图；第 346–382 行加工时间、侧位、旋转及装卸约束。
2. `../figures/generate_process_figures.py`：`chain_process`、`parallel_process`。
3. `../joint_model/seed.py`：`batch` 及链式构造中的 rotate → unload → load → exposure 次序。
4. `../joint_model/validate.py`：前侧装卸、旋转换侧、满片曝光及产品连续曝光检查。

运行 `python JMS-version/gif/generate_gifs.py` 可重新生成。依赖 Pillow 和中文字体（默认 Windows 微软雅黑）；输出包括 GIF、关键帧预览和本动画的逻辑/文件校验记录。校验不等同于完整设备排程验解。
