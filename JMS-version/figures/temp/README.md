# 8片与24片补充甘特图

每个批量包含 H=3、H=10 下纯4×1和纯2×2四张图；中英文各8张，格式为 PDF、SVG、PNG、TIFF。英文位于 en/。

24片纯2×2恢复为允许等待的已验解排程；8片纯2×2保留连续4 s交换排程。所有时刻来自 manifest.json 指定的解，不通过平移图形修改时序。

- 每张图仅保留资源时序面板，无局部放大；图示截至产品回片 Cmax，其后的末端清洁保留在原始解与时域记录中。
- 紫色斜线表示压力复位，蓝灰色表示机器人空载移位。
- 复位从模型记录的取片完成时刻立即开始，可与后续VTR动作重叠。
- 当前4 s取放动作未细分内部取片、移动及放片时刻；本图不推断更早的内部释放事件。
- 腔室灰色块表示交换或旋转，浅粉色表示等待，绿色表示500 s清洁处理。
