# 持续最优性求解：候选容量安全界

本记录对应 `tools/incumbent_sublevel.py` 的 `product_return_sublevel_capacity_v2`。本次改进不修改原始模型源码和已冻结实验，不降低最优性验收标准。4个目标算例均为16片、双源、纯4×1或纯2×2、H=3/10。

## 原问题与已知上界

令原问题目标为最后一片产品回片时间 Cmax，已有排程经独立物理验解和**原始完整候选模型**可行性认证后给出上界 U。于是原问题至少存在一个最优解满足 Cmax≤U。只要缩界仍包含该范围内的所有排程，就不会排除更优解，也没有固定配对、腔室分配、周期结构或机械手顺序。

## 周期与配对数量

所有生产周期至少包含一片产品，且必须在该产品回片之前结束。除每个腔室最多一个末端清洁周期外，其余清洁周期都在后续生产周期之前结束。末端清洁可以超过产品回片目标，不得用U直接截断整个物理时域。

由产品必经路径，第一次生产开始不早于L，最后一次生产结束不晚于U−R。当前参数下L=76秒、R=40秒。两者只累计必需取放、搬运、校准、泵/排气等时间，不包括任何人为等待，也不以历史图时刻为约束。因此每个腔室从首次生产至最后生产之间的加工及清洁时间总和不超过 W=U−L−R。

一个腔室有p个生产周期及c个非末端清洁周期时，必有：

- `1 ≤ p ≤ n_4x1 + 2*n_2x2`；
- `floor((p−1)/H) ≤ c ≤ p−1`（不能首次或连续清洁，至多H次生产后必须清洁）；
- `p*d_proc_min + c*t_clean ≤ W`。

枚举满足这些必要条件的整数(p,c)，取 `max(p+c+1)` 为每腔候选周期上限。额外的1完整保留可能发生在U之后的末端清洁。再与原始安全界、按总腔室工时推导的总周期界取最小值。这只是必要条件，未强制任何具体的生产或清洁组合。

每个周期占用两个配对。纯4×1配对及不含产品的辅助配对只出现一次；含产品的2×2配对恰好出现两次。因此活跃配对数 `P = 2*总周期数 − 含产品的2×2配对数`。后者至少为 `ceil(n_2x2/2)`，给出安全配对上限。活跃配对原本即为前缀编号，周期也是每腔前缀；删除超过界限的未激活候选，不改变物理排程。

对U=950秒的纯4×1、H=3算例，该推导给出P≤16、每腔Q≤4、总周期≤8；原界为P=64、每腔Q=32。时间时域仍为100000秒，没有截掉末端清洁。

## 有效不等式

另加入产品在腔室的最低总加工时间、沿路径的必需搬运时间、每腔生产工时界和单校准模块工作量界。所有产品均需独占AL至少28秒，最早首片开始AL占用为7秒；最后离开AL的产品仍需至少261秒完成余下路径。因此当前4组纯模式都满足 `Cmax ≥ 7 + 16*28 + 261 = 716秒`。该下界不使用历史固定布局的最优值。

## 认证边界

文稿结构重定时只用于产生可行上界，其条件最优不算全局证明。缩界搜索结果继续标记 `full_candidate_space=false` 和 `exact_incumbent_sublevel`，并保留原容量、缩界容量、推导版本与源码哈希，不伪装成未经缩界的原模型。

最终必须同时具备：有效上界的原模型认证、上述覆盖证明、缩界搜索的最优状态及闭合界、最终排程再次通过原始完整候选模型与独立物理验解。只有这条证据链完整，才可认证原问题Cmax的全局最优性。现有绘图门槛尚未放宽；未认证结果不会作为最优图发布。

枚举边界测试已覆盖末端清洁、阈值次数及两次曝光配对计数。纯4×1初步预检已接受950秒原模型认证解，并将下界从39秒提高到716秒。预检时限仅用于验证实现；正式主搜索不设置时间上限，达到内存限制或其他异常时仍属于未完成任务。
