# 双源模型的末端时间界：待独立预检的新版本

此强化不修改正在运行的搜索。适用范围限定为当前 `Integrated` 双源模型；任何实现或参数变化都必须重新检查前提。它保留主目标最优值，不声称保留所有无效等待的原始时间戳。

设已有原模型可行上界为U，安全容量为P、每腔Q，腔室数为m。对任意 Cmax≤U 的合法排程，保留所有不晚于U的时间点以及全部离散选择。U之后不再有产品事件、生产加工或非末端清洁；可能剩余的仅为VS辅助片操作、旋转和每腔至多一次末端清洁。跨越U的末端清洁同样保留固定时长。

固定配对、顺序、同步、槽位和清洁选择后，物理时间关系都是差分约束。将事件起止时间之外的路由别名收缩为相应事件变量；边界辅助变量只有零时差下界。暂不考虑驻留上界，保留U以前的精确时间，要求剩余点不早于U，取可行差分系统的最早完成解。原排程保证系统可行；系统不存在正权环，最长路径可取简单路径。涉及固定前缀的上界也不会被破坏，因为后缀时间只会提前。

至多有 `E=6P+2mQ` 个可能晚于U的事件：2P个配对装卸、4P个VS取放、2mQ次旋转。它们有2E个起止顶点，加上最多2m个末端清洁起止顶点。除清洁时长边外，正边权至多为 `d=max(handling, rotation, vtr_travel)`；清洁时长边在简单路径中至多出现m次。已完成产品的LL复位另保守预留 `max(upper_reset, lower_reset)`。因此有一种等目标的完成方式满足

`H_new = ceil(U + max(reset) + (2E+2m)*d + m*cleaning_time)`。

要求H_new不大于模块和机械手驻留上限，才能保证压缩后的任何驻留区间都自动满足被暂时忽略的驻留上界。本实现遇到不满足该前提的参数直接拒绝。若原时域已经更小，则沿用原时域，无需压缩。

辅助等待变量可按新时间差重新计算，其值在0到H_new之间；最大等待取这些值的最大值。激活节拍项对应连续的已用周期，周期起点单调，两个相邻间距之差绝对值不超过H_new；未激活项的Big-M约束不施加额外限制。其余Big-M按原模型公式以H_new重新生成，仍覆盖相应变量时域。

本轮三个容量组合得到2436、2759、3140秒，均小于10000秒驻留上限；它们都显式保留产品回片之后的末端清洁。不得把全时域直接设为U。

预检时只固定初始化解的配对、周期和U以前的时间，将晚于U的时间固定解除，完成一个压缩后的可行初始化。正式搜索必须解除全部初始化固定。最终证据仍需缩界及时间界覆盖论证、闭合主目标上下界、独立物理验解和原始100000秒完整模型认证；小规模测试或初始化成功本身不构成全局最优证明。

## 计入中间清洁的工时界

`cycle_work_bounds.py`另对每个腔室加入：产品回片Cmax不小于路径首尾时间加全部生产及非末端清洁时长。末端清洁用“本周期是清洁且下一周期未激活”的二元量识别并扣除，仍允许其晚于产品回片。

纯2×2情况下，令k为该腔产品配对数、b为被非末端清洁分隔的非空生产段数。每对产品需连续两次曝光，每周期至多一对首次曝光；一段中k_i对产品至少需要k_i+1个周期。因此 `p≥k+b`、`k≥b`、`k≤(H−1)b`，而每段最多H个生产周期。可选提前清洁仍被完整保留；同一段中若主动中断流水衔接，只会增加周期，不会违反这些必要条件。

16片产品至少需要8个产品配对，两腔中至少一腔承载4对。H=3时至少2段、6个生产周期和1次非末端清洁，故 `Cmax≥76+6*90+500+40=1156`。给定U=1398，单腔若承载5对则至少需要8个生产周期和2次非末端清洁，超出可用生产窗口，所以每腔至多4对。这些界不固定具体产品配对、腔室分配或机械手顺序。

既然总配对至少8而每腔至多4，两腔各恰好4对。对H=3、U=1398，枚举必要计数界进一步强制每腔恰好6个生产周期、1次非末端清洁，分成两段。每段最多3个生产周期，两段共6个，故两段都恰好3个；末段达到阈值，必须另有一次末端清洁。因此周期类型只能为“生产×3、清洁、生产×3、清洁”。这是由当前有效上界及模型规则推出的必要结构，不是人为选取文稿结构。`pure2_block_certificate.py`仅在计数上下界相等且所有段必满时才生成该强制类型；不满足这些条件的H=10算例不固定周期类型。配对成员、腔室指派、全部时间和机械手顺序仍参与全局搜索。
