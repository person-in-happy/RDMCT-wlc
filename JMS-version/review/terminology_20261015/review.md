## 全文术语约定

| 层次 | 统一用语与范围 |
| --- | --- |
| 对象 | 本文物料均为晶圆；晶圆分为产品晶圆和辅助晶圆。具体叙述使用晶圆来源、晶圆路线及晶圆任务。 |
| 加工 | 工艺腔室中生产与清洁的统称；加工类型集合含两种生产类型与清洁。 |
| 生产 | 按产品配方执行的工艺处理，采用 4×1 或 2×2 工艺模式。 |
| 周期 | 加工周期含生产周期与清洁周期；单次工艺处理对应一个生产周期。 |
| 时长 | 产品配方使用工艺时长；包含清洁的统一变量 d_m 使用加工类型持续时间。 |
| 清洁 | H 统一称清洁阈值，只累计生产周期；通常 H 后清洁，允许在满足下一周期为 2×2 的条件下提前至 H−1。 |
| 容量 | Pmax 是全批次候选 PW 对容量，Qmax 是每腔候选加工周期容量；两者均为上界。 |
| 晶圆任务 | 产品晶圆对应完整路线，辅助晶圆按每次借用建立供回任务；任务编号与可复用实体库存分别表示。 |
| 节拍 | 模型差分使用生产周期开始时刻的间隔；甘特图中交换间隔明确指前一生产周期结束至后一周期开始。 |
