# 3 方法概述

本文研究双源混流半导体组合设备调度问题。系统中同时存在产品 wafer 流与 PEC wafer 流，两类晶圆在共享旋转腔 `CH2 / CH3` 上耦合，并受到 `4x1` 与 `2x2` 两种模式的工艺规则约束。为此，本文首先建立精确 MIP 模型，再在 SCIP 的 branch-and-cut 框架上叠加学习式 cut selection。

## 3.1 新的输入与抽象层

与旧版本直接把“产品对”作为输入不同，当前模型以两种模式的产品 wafer 数量作为输入：

- `4x1` 模式产品 wafer 数量
- `2x2` 模式产品 wafer 数量
- PEC wafer 库存数量

随后由 MIP 在模式内部完成 wafer 到 PW 对的分配：

1. 同一 PW 对中的产品 wafer 必须来自同一模式。
2. 若某一模式的产品 wafer 数量为奇数，则该模式最后一个 PW 对由“1 片产品 wafer + 1 片 PEC wafer”构成。
3. 因此，PW 对既可以是“产品 + 产品”，也可以是“产品 + PEC”。

## 3.2 共享旋转腔调度层

在形成 PW 对后，MIP 继续对共享旋转腔中的时空分配建模。

对于 `4x1`：

- 每个槽位必须恰好容纳 2 个 PW 对
- 若只有 1 个产品承载 PW 对，则另一对由纯 PEC PW 对补足

对于 `2x2`：

- 产品承载 PW 对在每个腔体上形成有序前缀
- 首周期和尾周期分别使用纯 PEC PW 对形成边界
- 内部周期由相邻产品承载 PW 对交叠，保证产品 wafer 完成两次加工

## 3.3 关键变量族

模型主要包含四类变量：

1. wafer 到 PW 对的分配变量
2. `4x1` / `2x2` 的共享腔分配变量
3. 周期与时间连续性变量
4. PW 对完工时间、wafer 完工时间和 `c_max`

## 3.4 关键约束

核心约束包括：

1. 每片产品 wafer 只能进入一个同模式 PW 对。
2. 每个 PW 对的产品 wafer 容量固定为 2，或在奇数尾对中固定为 1。
3. 每个 `4x1` 槽位恰好容纳 2 个 PW 对，且禁止纯 PEC 空槽。
4. `2x2` 产品承载 PW 对形成前缀序列，并由此诱导首周期、内部周期和尾周期。
5. PEC 资源受全局库存约束，同时覆盖奇数尾对补位、`4x1` 槽位补足和 `2x2` 首尾边界。
6. 同一腔体上的 `4x1` 与 `2x2` 不能时间重叠。

## 3.5 目标函数

模型以所有产品 wafer 中的最大完工时间最小为目标，即：

`min c_max`

其中每片产品 wafer 的完工时间由其所属 PW 对的完工时间继承。
