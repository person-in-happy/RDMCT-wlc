# 发明名称
一种基于分层A3C与束搜索的双源混流旋转腔组合设备MIP求解方法

# 关键词
中文关键词：双源混流，旋转腔，混合整数规划，分层A3C，束搜索，强化学习，学习型割选择
英文关键词：dual-source mixed-flow, rotating chamber, mixed-integer programming, hierarchical A3C, beam search, reinforcement learning, learning-to-cut

# 1 相关技术背景（背景技术）

## 1.1 背景技术
双源混流旋转腔组合设备调度问题的核心，是在共享旋转腔、不同工艺模式并行、PEC wafer 参与补位、时序耦合强且切换频繁的条件下，对产品晶圆与 PEC wafer 的协同行为进行全局优化。对于这一类问题，单纯依赖规则调度虽然能够给出可行方案，但难以稳定处理复杂工艺约束；而直接由神经网络输出最终排程，则难以保证工艺可行性与全局最优性。

因此，更可靠的方式通常是先建立混合整数规划（MIP）模型，再通过 branch-and-cut 框架进行精确求解。设待求解的双源混流旋转腔调度模型记为：

min c^T x

s.t. A x <= b,

x = (x_I, x_C), x_I in Z^{n_I}, x_C in R^{n_C}。

其中，x_I 表示离散调度变量，x_C 表示连续时间变量。求解器通过在搜索树节点上不断求解 LP 松弛、生成候选割、加入有效不等式、进行分支和剪枝，逐步收缩可行域并逼近最优整数解。

但是，双源混流旋转腔设备的 MIP 模型具有以下特征：
1. 变量族多，既包含路径类变量、分配类变量，也包含时间类和完工类变量；
2. 候选割数量大，不同候选割对 LP 下界、求解时间和冗余程度的影响差别明显；
3. 传统求解器默认 cut selector 大多只利用通用统计量，未能利用“双源混流 + 旋转腔 + 共享腔室”的问题结构。

因此，本发明并不是用神经网络替代 MIP，而是在保持 MIP 精确性的前提下，设计一种能够嵌入 branch-and-cut 过程、智能选择候选割的分层 A3C 与束搜索方法，用于提升双源混流旋转腔调度 MIP 的整体求解效率。

## 1.2 与本发明相关的现有技术一

### 1.2.1 现有技术一的技术方案
现有技术一主要是传统的 MIP 精确求解方法。其典型流程为：
建立调度 MIP；
在根节点和后续分支节点上求解 LP 松弛；
调用求解器内置分离器生成候选割；
利用默认 cut selector 依据候选割的 efficacy、support、违反度等统计量选择一部分候选割加入当前节点 LP；
反复进行“加割 - 重新求 LP - 分支 - 剪枝”，直到达到停止条件。

该类方法的优点是结果可解释、终止时能够给出严格的最优性证明或界；其不足在于 cut selection 机制通常是规则化和问题无关的。

### 1.2.2 现有技术一的缺点
1. 只依据通用割统计特征，无法识别双源混流旋转腔调度模型中的结构差异。
2. 无法针对不同节点、不同候选割池规模自适应决定“保留多少割”和“先保留哪些割”。
3. 在候选割数量较大时，容易出现保留过多导致 LP 负担过重，或保留过少导致下界收紧不足的问题。
4. 对共享旋转腔、PEC 预算和不同变量族之间的耦合关系缺乏结构性利用，导致求解效率受限。

## 1.3 与本发明相关的现有技术二

### 1.3.1 现有技术二的技术方案
现有技术二主要是面向整数规划求解加速的学习型方法或面向调度问题的强化学习方法。其典型方案包括：
1. 用强化学习决定分支变量、节点选择或候选割选择；
2. 用注意力网络、指针网络或图神经网络对候选动作集合建模；
3. 在推理阶段使用 greedy 或 beam search 生成动作序列。

这类方法相比传统规则更灵活，但多数只适用于通用 MILP 或标准作业车间问题，并未针对双源混流旋转腔设备中的结构变量族和求解特征进行专门设计。

### 1.3.2 现有技术二的缺点
1. 仅把候选割看成“匿名向量”，忽略了割系数主要作用于哪一类变量。
2. 通常只学习一个平面动作，不同时学习“割数量”和“割顺序”，动作表达能力不足。
3. 纯贪心解码容易陷入局部最优，前几步错误选择会迅速放大。
4. 很少系统说明加入学习策略后如何在理论上保持 MIP 精确求解的有效性。

# 2 本发明技术方案的详细阐述（发明内容）

## 2.1 本发明所要解决的技术问题（发明目的）
本发明要解决的技术问题是：
对于双源混流旋转腔组合设备，如何先建立能够精确表达设备运行逻辑的 MIP 模型，再在该 MIP 的 branch-and-cut 求解过程中，以分层 A3C 和束搜索自适应决定候选割的保留比例和保留顺序，从而在不改变整数可行解集合的前提下，提高 LP 下界收紧效率、减少搜索节点数、缩短求解时间，并最终得到满足工艺约束的最优或高质量整数调度解。

具体而言，本发明同时解决以下两个层面的技术问题：
1. 建模层面，如何将双源混流、旋转腔共享、PEC 补位和完工时间最小化统一编码为一个精确 MIP；
2. 求解层面，如何将候选割选择问题转化为可训练、可推理、可嵌入求解器的分层强化学习问题，并保持 MIP 精确求解的理论正确性。

## 2.2 本发明提供的完整技术方案（发明方案）

### 2.2.1 总体技术路线
本发明的总体路线分为两部分：

第一部分是双源混流旋转腔组合设备的精确 MIP 建模。该 MIP 负责完整刻画产品晶圆、PEC wafer、4x1 模式、2x2 模式、共享旋转腔、时间关系和完工时间目标。

第二部分是面向该 MIP 的分层 A3C + 束搜索求解机制。该机制嵌入 branch-and-cut，在每一轮分离过程中根据候选割状态决定保留比例和保留序列，并在不破坏整数可行域的前提下提升求解效率。

因此，本发明输出的最终解仍由精确 MIP 求解器返回，而强化学习部分负责优化 MIP 的求解路径。

### 2.2.2 双源混流旋转腔调度MIP的集合、参数与变量
设共享旋转腔集合为：

M = {CH2, CH3}。

设 4x1 模式产品晶圆集合为 W_F，2x2 模式产品晶圆集合为 W_M。
设 4x1 模式的 PW 对集合为 P_F，2x2 模式的 PW 对集合为 P_M。

设在腔室 m 中：
4x1 槽位集合为 F_m；
2x2 位置集合为 R_m；
2x2 周期集合为 C_m。

设参数如下：
N_PEC 为 PEC wafer 总库存；
beta 为一对 PW 的聚合转运时间；
mu 为同一腔内相邻加工块之间的最小切换间隔；
t_F 为 4x1 单槽工艺时间；
t_B 为 2x2 边界周期时间；
t_I 为 2x2 内部周期时间；
M_big 为大 M 常数。

定义聚合时长：

T_F = t_F + 2 * beta，

T_B = t_B + 2 * beta，

T_I = t_I + 2 * beta。

为了描述晶圆到 PW 对、PW 对到腔室及时间安排，本发明引入如下核心变量：

1. 晶圆到 PW 对映射变量
x^F_{w,p} = 1，表示 4x1 产品晶圆 w 分配给 4x1 PW 对 p；
x^M_{w,p} = 1，表示 2x2 产品晶圆 w 分配给 2x2 PW 对 p。

2. 4x1 共享旋转腔调度变量
y^F_{p,m,f} = 1，表示 4x1 PW 对 p 分配到腔室 m 的槽位 f；
u^F_{m,f} = 1，表示腔室 m 的槽位 f 被 4x1 使用；
e^F_{m,f} = 1，表示该槽位需补入一个纯 PEC PW 对；
a^F_{m,f} = 1，表示该 4x1 槽位位于同腔 2x2 块之后。

3. 2x2 共享旋转腔调度变量
y^M_{p,m,r} = 1，表示 2x2 PW 对 p 分配到腔室 m 的位置 r；
u^M_{m,r} = 1，表示腔室 m 的位置 r 被 2x2 产品 PW 对占用；
q^M_{m,c} = 1，表示腔室 m 的第 c 个 2x2 周期存在；
g_m = 1，表示腔室 m 存在 2x2 序列；
l^M_{m,c} = 1，表示周期 c 是该腔室 2x2 序列的最后有效周期。

4. 时间和完工变量
s^F_{m,f}, c^F_{m,f} 分别表示 4x1 槽位的开始和结束时间；
s^M_{m,c}, c^M_{m,c} 分别表示 2x2 周期的开始和结束时间；
E_m^M 表示腔室 m 中 2x2 连续块的结束时间；
C_p^F, C_p^M 分别表示 4x1 和 2x2 PW 对的完工时间；
C_w 表示产品晶圆 w 的完工时间；
C_max 表示总体最大完工时间。

### 2.2.3 双源混流MIP的核心建模约束

#### （一）产品晶圆到PW对的映射
每个产品晶圆必须且仅能映射到一个与其模式一致的 PW 对：

sum_{p in P_F} x^F_{w,p} = 1, forall w in W_F，

sum_{p in P_M} x^M_{w,p} = 1, forall w in W_M。

若设 L_p^F 和 L_p^M 分别表示各 PW 对承载的产品晶圆数量，则：

sum_{w in W_F} x^F_{w,p} = L_p^F, forall p in P_F，

sum_{w in W_M} x^M_{w,p} = L_p^M, forall p in P_M。

其中：
L_p^F in {1, 2}，
L_p^M in {1, 2}。

若某模式产品晶圆数为偶数，则所有该模式 PW 对满足 L_p = 2；
若为奇数，则最后一个 PW 对满足 L_p = 1，其空缺位置由 1 片 PEC wafer 补齐。

为减少对称性，引入顺序保持约束：

sum_{p in P_F} p * x^F_{w_i,p} <= sum_{p in P_F} p * x^F_{w_{i+1},p}，

sum_{p in P_M} p * x^M_{w_i,p} <= sum_{p in P_M} p * x^M_{w_{i+1},p}。

#### （二）4x1 模式在共享旋转腔中的调度
每个 4x1 PW 对必须且仅能分配一次：

sum_{m in M} sum_{f in F_m} y^F_{p,m,f} = 1, forall p in P_F。

每个被使用的 4x1 槽位必须恰好容纳两对 PW：

sum_{p in P_F} y^F_{p,m,f} + e^F_{m,f} = 2 * u^F_{m,f}, forall m,f。

为禁止“纯 PEC 槽位”，加入：

u^F_{m,f} <= sum_{p in P_F} y^F_{p,m,f}, forall m,f。

为保证 4x1 槽位前缀使用，加入：

u^F_{m,f} >= u^F_{m,f+1}。

该组约束说明：一个 4x1 槽位要么承载 2 对产品 PW，要么承载 1 对产品 PW 与 1 对纯 PEC PW，不允许没有产品片却单独使用槽位。

#### （三）2x2 模式在共享旋转腔中的调度
每个 2x2 PW 对必须且仅能分配一次：

sum_{m in M} sum_{r in R_m} y^M_{p,m,r} = 1, forall p in P_M。

位置占用与分配一致：

sum_{p in P_M} y^M_{p,m,r} = u^M_{m,r}, forall m,r。

位置前缀性：

u^M_{m,r} >= u^M_{m,r+1}。

为了把 2x2 的“首边界周期 + 若干内部周期 + 尾边界周期”刻画为连续加工块，构造周期存在变量 q^M_{m,c}，并满足：

q^M_{m,1} = u^M_{m,1}，

q^M_{m,c} >= u^M_{m,c-1}, 2 <= c <= |C_m|-1，

q^M_{m,c} >= u^M_{m,c}, 2 <= c <= |C_m|-1，

q^M_{m,c} <= u^M_{m,c-1} + u^M_{m,c}, 2 <= c <= |C_m|-1，

q^M_{m,|C_m|} = u^M_{m,|R_m|}。

最后有效周期满足：

g_m = sum_{c in C_m} l^M_{m,c}，

l^M_{m,c} <= q^M_{m,c}，

l^M_{m,c} + q^M_{m,c+1} <= 1，

l^M_{m,c} >= q^M_{m,c} - q^M_{m,c+1}。

#### （四）PEC wafer 统一预算
PEC wafer 的消耗由三部分组成：
1. 奇数尾片导致的内部补位；
2. 4x1 中纯 PEC PW 对补位；
3. 2x2 序列首尾边界 PEC 对。

设 I_internal 为奇数尾片导致的内部 PEC 用量，则统一预算为：

I_internal + 2 * sum_{m in M} sum_{f in F_m} e^F_{m,f} + 4 * sum_{m in M} g_m <= N_PEC。

该式将双源混流中的 PEC 使用从局部补位问题转化为全局受限资源优化问题。

#### （五）4x1 与 2x2 在同一旋转腔内的共腔时序
4x1 槽位时长为：

c^F_{m,f} = s^F_{m,f} + T_F * u^F_{m,f}。

同一腔室内相邻 4x1 槽位的衔接满足：

s^F_{m,f+1} >= c^F_{m,f} + mu - M_big * (2 - u^F_{m,f} - u^F_{m,f+1})。

2x2 周期时长满足：

c^M_{m,1} = s^M_{m,1} + T_B * q^M_{m,1}，

c^M_{m,|C_m|} = s^M_{m,|C_m|} + T_B * q^M_{m,|C_m|}，

c^M_{m,c} = s^M_{m,c} + T_B * q^M_{m,c} + (T_I - T_B) * u^M_{m,c}, 2 <= c <= |C_m|-1。

相邻周期衔接满足：

s^M_{m,c+1} >= c^M_{m,c} + mu - M_big * (1 - q^M_{m,c+1})，

s^M_{m,c+1} <= c^M_{m,c} + mu + M_big * (2 - q^M_{m,c} - q^M_{m,c+1})。

2x2 连续块结束时间由最后有效周期决定：

E_m^M >= c^M_{m,c} - M_big * (1 - l^M_{m,c})，

E_m^M <= c^M_{m,c} + M_big * (1 - l^M_{m,c})。

为了表示 4x1 与 2x2 可以共用同一旋转腔，但二者在同一腔内不得时间重叠，引入前后标记 a^F_{m,f}，并写成：

c^F_{m,f} <= s^M_{m,1} - mu + M_big * a^F_{m,f}
+ M_big * (1 - u^F_{m,f}) + M_big * (1 - g_m)，

s^F_{m,f} >= E_m^M + mu - M_big * (1 - a^F_{m,f})
- M_big * (1 - u^F_{m,f}) - M_big * (1 - g_m)。

该组约束线性化地表达了同一共享旋转腔中的“4x1 槽位块”与“2x2 连续块”前后排布关系。

#### （六）完工时间映射与目标函数
4x1 PW 对完工时间由其所处槽位结束时间决定：

C_p^F >= c^F_{m,f} - M_big * (1 - y^F_{p,m,f})，

C_p^F <= c^F_{m,f} + M_big * (1 - y^F_{p,m,f})。

2x2 PW 对完工时间由其第二次通过结束的下一周期决定：

C_p^M >= c^M_{m,r+1} - M_big * (1 - y^M_{p,m,r})，

C_p^M <= c^M_{m,r+1} + M_big * (1 - y^M_{p,m,r})。

产品晶圆继承所属 PW 对完工时间：

C_w >= C_p^F - M_big * (1 - x^F_{w,p})，

C_w <= C_p^F + M_big * (1 - x^F_{w,p})，

C_w >= C_p^M - M_big * (1 - x^M_{w,p})，

C_w <= C_p^M + M_big * (1 - x^M_{w,p})。

最大完工时间定义为：

C_max >= C_w, forall w。

优化目标为：

min C_max。

至此，双源混流旋转腔组合设备调度的 MIP 模型完整建立。该模型给出了从产品晶圆与 PEC wafer 协同补位，到共享旋转腔时间安排，再到最大完工时间最小化的精确数学表达。

### 2.2.4 将候选割选择转化为学习问题
在上述 MIP 进入 branch-and-cut 求解后，设第 n 个搜索节点、该节点第 t 轮分离时刻的 LP 松弛多面体为：

P_t^{(n)} = {x | A_n x <= b_n, G_t x <= h_t}，

其中 A_n x <= b_n 包括原模型约束和当前节点分支约束，G_t x <= h_t 表示此前已加入的有效割。其 LP 下界为：

z_t^{(n)} = min {c^T x | x in P_t^{(n)}}。

若此时分离器生成候选割池：

C_t^{(n)} = {gamma_1^t, gamma_2^t, ..., gamma_{N_t}^t}，

其中 gamma_i^t 表示一个候选有效割：

a_i^{tT} x <= beta_i^t，

并满足对所有整数可行解 x in X_IP 都成立：

a_i^{tT} x <= beta_i^t, forall x in X_IP。

则加入这些割不会删除任何整数可行调度，只会收紧 LP 松弛。理想情况下，希望在候选割池中找到一个子集 Y，使得加入这些割后，LP 下界提升尽可能大，而计算开销和冗余尽可能小，可写成：

Y_t^* = argmax_{Y subseteq C_t^{(n)}, |Y| = K}
[ E(z_{t+1}^{(n)}(Y) - z_t^{(n)}) - lambda_1 tau(Y) - lambda_2 red(Y) ]。

其中：
tau(Y) 表示加入这些割带来的额外 LP 负担；
red(Y) 表示候选割之间的冗余程度。

由于直接求解该组合优化问题代价极高，本发明采用“分层 A3C + 束搜索 + 结构修复”的方式进行近似求解。

### 2.2.5 候选割状态表示与结构感知特征
本发明将每个候选割 gamma_i^t 映射为一个特征向量 h_i^t，并将全部候选割表示为状态矩阵：

H_t = [h_1^t, h_2^t, ..., h_{N_t}^t]^T in R^{N_t x d}。

特征向量 h_i^t 由两类信息构成：
1. 通用割质量特征；
2. 面向双源混流旋转腔 MIP 的结构感知特征。

通用割质量特征包括：
obj_parallelism_i，
efficacy_i，
support_i，
integral_support_i，
violation_i。

为了反映一个割主要作用于哪一类结构变量，将原 MIP 中变量划分为：

F = {route, full_assign, mix_assign, timing, completion, other}。

设第 i 个候选割在变量族 f 上的绝对系数质量为：

m_{i,f} = sum_{j in J_f} |a_{i,j}|。

则归一化变量族比例为：

phi_{i,f} = m_{i,f} / (sum_{g in F} m_{i,g} + epsilon)。

因此：

sum_{f in F} phi_{i,f} = 1。

进一步定义结构熵：

H_i^{fam} = - [sum_{f in F} phi_{i,f} ln(phi_{i,f} + epsilon)] / ln(|F|)。

定义结构化比例：

R_i^{struct} = 1 - phi_{i,other}。

定义主导变量族比例：

R_i^{dom} = max_{f in F \\ {other}} phi_{i,f}。

定义二元变量占比与连续变量占比：

R_i^{bin} = (sum_{j in J_bin} |a_{i,j}|) / (sum_j |a_{i,j}| + epsilon)，

R_i^{cont} = (sum_{j in J_cont} |a_{i,j}|) / (sum_j |a_{i,j}| + epsilon)。

于是候选割特征写为：

h_i^t = [obj_parallelism_i, efficacy_i, support_i, integral_support_i, violation_i,
phi_{i,*}, R_i^{bin}, R_i^{cont}, R_i^{dom}, H_i^{fam}, ...]。

该状态表示使策略网络能够区分“这个割更偏向路径约束”“这个割更偏向 4x1 分配约束”“这个割更偏向 2x2 时序约束”等结构语义，而不是把所有候选割视为无差别的匿名向量。

### 2.2.6 分层A3C中的高层策略：保留比例决策
设高层策略网络对状态矩阵 H_t 编码后得到汇聚状态向量 s_t。高层 actor 输出高斯分布参数：

mu_t, log sigma_t = f_eta^{high}(s_t)。

通过重参数化采样：

u_t = mu_t + sigma_t * xi_t, xi_t ~ N(0, I)。

经 tanh 压缩后得到动作：

a_t = tanh(u_t)。

再映射为候选割保留比例：

rho_t = 0.5 * (a_t + 1), rho_t in (0, 1)。

由此得到保留数量：

K_t = min{N_max, max{2, floor(rho_t * N_t)}}。

高层策略由此能够根据候选割池规模、结构分布和当前 LP 状态自适应决定“保留多少割”，避免人为固定比例。

其对数概率为：

log pi_eta(rho_t | H_t)
= log N(u_t; mu_t, sigma_t^2) - sum_q log(1 - a_{t,q}^2 + epsilon)。

### 2.2.7 分层A3C中的低层策略：候选割序列决策
在高层给定 K_t 后，低层策略负责从 N_t 个候选割中选出一个长度为 K_t 的有序序列：

Y_t = (y_{t,1}, y_{t,2}, ..., y_{t,K_t})。

本发明采用 pointer network 对候选割组合进行序列化建模。首先由编码器对每个候选割特征进行嵌入：

e_i = Encoder(h_i^t)。

在第 l 步，解码器状态记为 q_l，则对每个尚未选择的候选割 i 计算注意力打分：

u_{l,i} = v^T tanh(W_q q_l + W_e e_i + b)。

施加已选掩码后，得到条件概率：

p_{l,i} = exp(u_{l,i}) / sum_{j in U_l} exp(u_{l,j})，

其中 U_l 为第 l 步尚未被选择的候选割索引集合。

于是整个序列的条件概率可分解为：

pi_theta(Y_t | H_t, K_t)
= product_{l=1}^{K_t} pi_theta(y_{t,l} | H_t, y_{t,<l})。

该分解把原本复杂的候选割子集选择问题转化为序列决策问题，便于训练和推理。

### 2.2.8 束搜索近似求解最优候选割序列
纯贪心方法在前几步一旦做出错误选择，后续空间会迅速恶化。为此，本发明在低层推理时采用束搜索。

设束宽为 B。对任一长度为 l 的部分序列 Y_{t,1:l}，定义其路径分数为：

Score_beam(Y_{t,1:l}) = sum_{r=1}^{l} log p_{r, y_{t,r}}。

每一步扩展时，对当前束中每条路径附加一个新的未选候选割，并只保留分数最高的 B 条路径。最终得到：

Y_t^{beam} = argmax_{Y in Beam_B(H_t, K_t)} Score_beam(Y)。

束搜索近似求解的目标等价于：

Y_t^{MAP} = argmax_{Y, |Y| = K_t} log pi_theta(Y | H_t, K_t)。

因此，相比单纯贪心，束搜索更接近序列最大后验解，在理论和实践上都能有效降低早期误选的连锁影响。

### 2.2.9 基于变量族配额的结构修复与重排
低层策略与束搜索主要优化序列概率，但不直接约束候选割之间的结构冗余。为此，本发明在 beam 解码之后引入 family-aware 结构修复与重排。

首先根据候选割特征计算基础质量分：

Base_i = 0.36 Eff_i + 0.24 Viol_i + 0.15 IntSup_i
+ 0.15 R_i^{struct} + 0.10 R_i^{dom} - 0.05 H_i^{fam}。

然后在候选排名前窗中统计各变量族质量：

Mass_f = sum_{i in TopWindow} phi_{i,f}。

由此构造变量族目标配额：

Quota_f = round( K_t * Mass_f / (sum_g Mass_g + epsilon) )。

再定义候选割 i 与候选割 j 的结构相似度：

sim(i, j) = <xi_i, xi_j> / (||xi_i|| ||xi_j|| + epsilon)，

其中 xi_i 由核心通用特征与变量族比例特征拼接而成。

对大小为 K_t 的候选割集合 Y，定义其修复目标函数：

F(Y) = sum_{i in Y} Base_i
- lambda_s sum_{i<j, i,j in Y} sim(i,j)
- lambda_q sum_f max(0, n_f(Y) - Quota_f)。

其中 n_f(Y) 表示集合 Y 中主导变量族为 f 的候选割数量。该目标函数具有三重含义：
1. 优先保留质量高的割；
2. 惩罚结构相似、冗余度高的割；
3. 避免所有保留割集中在单一变量族上。

最终采用近似贪心修复获得：

Y_t^{final} = Repair(Y_t^{beam}, H_t, Quota)。

### 2.2.10 有效割加入后的状态转移与理论保证
将最终候选割集合 Y_t^{final} 加入当前节点 LP 松弛后，得到新的多面体：

P_{t+1}^{(n)} = P_t^{(n)} cap ( intersection_{gamma in Y_t^{final}} H_gamma )，

其中：

H_gamma = {x | a_gamma^T x <= beta_gamma}。

由于每个 gamma 都是对整数可行解集 X_IP 的有效不等式，因此有：

X_IP subseteq P_{t+1}^{(n)} subseteq P_t^{(n)}。

这意味着：
1. 整数可行解集合不变，本发明不会删除任何合法调度解；
2. LP 松弛被收紧，因此在最小化问题中 LP 下界单调不减：

z_t^{(n)} <= z_{t+1}^{(n)} <= z_IP^*，

其中 z_IP^* 为 MIP 最优值。

该性质给出了本发明嵌入精确求解器后的理论基础：学习策略只影响“求解速度”和“下界收紧效率”，不改变有效割的数学正确性，也不改变最终精确求解的目标。

### 2.2.11 本发明如何一步一步求解MIP并得到最终解
本发明的一次完整求解过程如下。

步骤 S1：建立并读取双源混流旋转腔调度的 MIP 模型。
根据产品晶圆、PEC wafer、4x1/2x2 模式、共享旋转腔和时间参数建立上述 MIP，并装载到求解器中。

步骤 S2：构造根节点 LP 松弛。
去除整数约束后得到根节点 LP，求得初始 LP 解 x_{LP}^{(0)} 和下界 z_0。

步骤 S3：在当前节点执行分离过程，生成候选割池。
记当前节点为 n、当前分离轮次为 t，则由求解器分离器生成候选割集合 C_t^{(n)}，并提取每个候选割的通用特征和结构特征，组成状态矩阵 H_t。

步骤 S4：高层 A3C 策略计算保留比例。
根据 H_t 输出 rho_t，并据此确定保留数量 K_t。

步骤 S5：低层 pointer policy 生成候选割序列。
低层策略以 H_t 和 K_t 为输入，输出候选割的条件概率分布。

步骤 S6：束搜索生成高概率保留序列。
采用 beam width 为 B 的束搜索近似求取 Y_t^{beam}。

步骤 S7：执行 family-aware 结构修复。
根据基础质量分、相似度惩罚和变量族配额，对 Y_t^{beam} 重排和修复，得到 Y_t^{final}。

步骤 S8：将 Y_t^{final} 中的有效割加入当前 LP 松弛。
求解器重新优化 LP，得到新的下界 z_{t+1}^{(n)} 以及新的 LP 解 x_{LP}^{(n,t+1)}。

步骤 S9：判断当前节点是否可剪枝或是否需要分支。
若 x_{LP}^{(n,t+1)} 已满足整数约束，则得到一个新的可行调度解，并据此更新 incumbent；
若 x_{LP}^{(n,t+1)} 非整数，且 z_{t+1}^{(n)} 已不优于当前 incumbent，则剪枝；
若仍具有改进可能，则按既定分支规则生成子节点。

步骤 S10：在所有活动节点上重复执行步骤 S3 至步骤 S9。
在此过程中，学习策略反复参与候选割选择，但搜索树维护、LP 重新求解、分支和最优性验证仍由精确 MIP 求解器完成。

步骤 S11：满足终止条件后输出最终解。
设当前最优可行解上界为 z_inc，全局下界为 z_LB，则最优性差距定义为：

Gap = (z_inc - z_LB) / (|z_inc| + epsilon)。

当活动节点为空，或者 Gap <= delta 时，求解器终止。若活动节点为空，则 incumbent 对应的调度解即为全局最优整数解；若达到允许误差阈值，则 incumbent 为该容差下的最终高质量解。

因此，本发明得到最终解的过程不是“神经网络直接生成解”，而是：
“先由 MIP 精确表达调度可行域，再由强化学习在 branch-and-cut 内部决定更优的有效割子集，促使 LP 下界更快逼近整数最优值，最后由精确求解器完成分支、剪枝与最终解输出。”

### 2.2.12 分层A3C训练机制及其理论目标
本发明采用 A3C 风格并行训练框架。设共有 K 个并行工作器，每个工作器独立在不同实例或不同随机种子下运行求解过程，并收集轨迹数据。

对一次求解过程，定义回报：

R = - alpha T_solve - beta N_nodes - gamma D_pdi - delta G_final，

其中：
T_solve 为求解时间；
N_nodes 为搜索树节点数；
D_pdi 为 primal-dual integral；
G_final 为最终最优性差距。

高层与低层策略共享“使回报最大化”的目标，即：

J(theta, eta) = E[R]。

设 critic 网络输出状态价值：

V_psi(H_t)。

则优势函数为：

A_t = R_t - V_psi(H_t)。

低层 actor 的策略梯度目标为：

grad_theta J_low
= E[ A_t grad_theta log pi_theta(Y_t | H_t, K_t) ]。

高层 actor 的策略梯度目标为：

grad_eta J_high
= E[ A_t grad_eta log pi_eta(rho_t | H_t) ]。

critic 损失为：

L_value(psi) = E[ (V_psi(H_t) - R_t)^2 ]。

在加入熵正则项的情况下，总体损失为：

L = - J_low - lambda_h J_high + lambda_v L_value - lambda_e H(pi)。

并行工作器的梯度聚合为：

g = (1 / K) sum_{k=1}^{K} g_k。

该训练机制使策略网络不再依赖人工经验规则，而是通过大量求解轨迹自动学习“什么样的割组合更有利于更快收紧下界并更快结束搜索”。

### 2.2.13 算法复杂度与理论分析
对于规模为 N_t 的候选割池，若直接穷举所有大小为 K_t 的候选割子集，其复杂度近似为：

O( C(N_t, K_t) )，

在实际求解中不可接受。

本发明通过“比例决策 + 序列决策”的分层分解，将组合子集优化问题转化为：
高层 O(1) 量级的比例推理；
低层 O(B K_t N_t) 量级的 beam search 序列推理；
以及 O(K_t N_t) 量级的结构修复。

因此，在候选割规模较大时，本发明仍具有工程可行性。

从理论上看，本发明具有三层保证：
1. 有效割保证整数可行域不被破坏；
2. LP 下界在最小化问题中单调不减；
3. 终止时的 incumbent 仍由精确 MIP 求解器返回，因此在完整搜索结束时保持全局最优性。

换言之，本发明学习的是“求解路径的优化”，而不是“可行域的替换”。

## 2.3 本发明技术方案带来的有益效果
1. 在建模层面，能够精确表示双源混流、PEC 补位、共享旋转腔以及完工时间最小化目标，模型语义清晰、可解释性强。
2. 在求解层面，把候选割选择从固定规则转化为可学习的分层决策过程，能够针对不同节点和不同实例自适应选择保留比例。
3. 通过结构感知特征，策略网络能够识别双源混流旋转腔调度模型中不同变量族的作用差异，更有效地选择有价值的割。
4. 通过束搜索提高低层序列决策的稳定性和近似最优性，克服贪心策略易早期失误的问题。
5. 通过 family-aware 修复显著降低冗余割和同类割过度集中的现象，使加入求解器的有效割集合更均衡。
6. 由于只选择有效割而不改变整数可行解集合，因此在理论上保持了精确 MIP 求解的正确性。
7. 在工程上，本发明显著降低求解时间、搜索节点数和 primal-dual integral，更适合双源混流旋转腔设备的复杂调度求解。

# 3 针对2中的技术方案，是否还有别的替代方案同样能完成发明目的
1. 高层比例策略可由连续动作改为离散动作，即直接从若干比例档位中选择。
2. 低层序列策略可采用 Transformer 解码器、图注意力解码器或带终止标记的指针网络实现。
3. 束搜索可替换为贪心加多次采样、蒙特卡洛树搜索或其他近似最大后验序列搜索方法。
4. 结构修复中的目标函数可改写为子模近似形式、DPP 风格多样性目标或基于图聚类的冗余抑制目标。
5. A3C 可替换为 PPO、IMPALA 或其他 actor-critic 变体，但仍属于“分层强化学习求解候选割组合”的同一发明思想。
6. 该方法不仅适用于当前双源混流旋转腔组合设备，也可推广到其他具有共享资源、多模式耦合和大规模候选割池的半导体设备调度 MIP。

# 4 本发明的技术关键点和欲保护点是什么
1. 面向双源混流旋转腔组合设备调度建立以 PW 对形成、共享旋转腔共腔时序和统一 PEC 预算为核心的精确 MIP 模型。
2. 将该 MIP 求解过程中的候选割选择定义为分层决策问题的思想。
3. 在高层策略中输出候选割保留比例 rho_t，并据此自适应确定保留数量 K_t 的方法。
4. 在低层策略中用 pointer network 对候选割保留顺序进行序列化建模的方法。
5. 在候选割推理阶段采用 beam search 近似求解最大后验候选割序列的方法。
6. 基于 route、full_assign、mix_assign、timing、completion 等变量族构造结构感知候选割特征的方法。
7. 基于变量族配额、结构相似度惩罚和基础质量分进行 family-aware 修复重排的方法。
8. 将上述学习型候选割选择机制嵌入 branch-and-cut，并保持有效割不破坏整数可行域的精确 MIP 求解框架。
9. 利用分层 A3C 并行训练，以求解时间、节点数、原始对偶积分和最终 gap 构造回报函数的训练方法。
10. 上述方法在双源混流旋转腔组合设备调度中的应用，以及对应的装置、设备和存储介质。
