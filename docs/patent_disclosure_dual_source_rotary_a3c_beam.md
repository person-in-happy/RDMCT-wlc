# 发明名称
一种面向双源混流旋转腔组合设备调度的结构感知 A3C-束搜索求解方法

# 关键词
中文关键词：组合设备，双源混流，旋转腔，混合整数规划，结构感知割选择，A3C，束搜索

英文关键词：cluster tools, dual-source mixed flow, rotary chamber, mixed integer programming, structure-aware cut selection, A3C, beam search

# 1 相关技术背景（背景技术）

## 1.1 背景技术

半导体制造过程中，组合设备（Cluster Tools，CT）通常由负载锁、校准模块、机械手、若干工艺模块以及必要的缓存或保护模块组成，用于实现多道真空工艺的连续加工。随着器件结构日益复杂，传统单腔或普通 PM 已难以在有限占地下同时兼顾吞吐量、工艺柔性与一致性，因此在单一腔体内部集成多个工艺位与内置旋转机构的旋转腔设备逐渐成为高端制程的重要装备形态。

在本发明关注的设备场景中，存在两条不同来源但在旋转腔内耦合的晶圆流：第一条为产品晶圆流，第二条为存放在 PEC storage 中、用于补位和保护腔底的 PEC wafer 流。产品晶圆与 PEC wafer 在进入旋转腔时合流，在加工完成后又分别返回不同后续路径，因此该问题属于典型的双源混流调度问题。

进一步地，本发明对应的设备中存在两个共享旋转腔 `CH2` 和 `CH3`，且两个旋转腔都可以执行两种不同工艺模式：

1. `4x1` 模式：四个工艺位同时装满后统一加工一次，再统一卸载；
2. `2x2` 模式：借助前导 PEC wafer 与尾部 PEC wafer 构造边界，使产品晶圆对在相邻周期内完成两次加工，而首尾 PEC wafer 只加工一次。

为保证建模精度与求解规模之间的平衡，项目代码采用“产品对”抽象：每两个产品晶圆组成一个产品对，每两个 PEC wafer 组成一个 PEC 对。由此可以在不显著损失工艺语义的前提下，对旋转腔中的批次补位、流水衔接、PEC 首尾边界以及完工时间进行精确描述。

双源混流旋转腔组合设备调度问题同时包含以下难点：

1. 共享旋转腔上的 `4x1` 与 `2x2` 两种模式不能时间重叠，但都可能分配到同一腔体；
2. `4x1` 模式下 PEC 只允许作为补位，不允许形成纯 PEC 空批；
3. `2x2` 模式下产品对必须形成有序前缀序列，并自动诱导出前导周期、内部周期与尾周期；
4. PEC 使用量受全局库存约束，且 `4x1` 补位与 `2x2` 首尾边界会共同消耗 PEC 资源；
5. 随着实例规模增大，混合整数规划（MIP）在分支定界求解时会产生大量候选割，若仅依赖默认割选择策略，求解时间和节点数都会迅速上升。

因此，该问题不仅需要精确的数理优化模型来严格表达工艺物理约束，还需要一种能够贴合模型结构的学习式求解加速方法，在不破坏精确求解可行性的前提下提高分支定界效率与最终解质量。

## 1.2 与本发明相关的现有技术一

### 1.2.1 现有技术一的技术方案

现有技术一主要是针对半导体组合设备或旋转腔设备调度问题建立混合整数规划模型，然后直接调用通用 MIP 求解器（如 SCIP、CPLEX、Gurobi 等）自带的 branch-and-cut 机制进行求解。其典型方案包括：

1. 使用二进制变量表示产品批次是否分配到某个腔体、某个槽位或某个加工位置；
2. 使用连续变量表示各槽位、各加工周期以及各产品批次的开始时间、结束时间和完工时间；
3. 用大 M 约束、顺序约束和容量约束描述不同批次在同一资源上的先后关系；
4. 将构造好的 `.lp` 或 `.mps` 模型送入求解器，由求解器自行完成分支、割平面生成、割排序与节点扩展。

这类方案的优点是建模精确、约束可解释性强，能够保持严格的工艺可行性；但其割选择与割排序主要依赖求解器默认策略，无法针对双源混流旋转腔问题的变量结构进行专门优化。

### 1.2.2 现有技术一的缺点

与本发明相比，现有技术一至少存在以下缺点：

1. 仅在模型层面刻画了旋转腔与双源混流约束，但没有在求解层面利用这些结构语义。求解器在分离阶段产生的大量候选割被统一视为通用线性不等式，无法区分“作用于共享腔分配变量的关键割”和“仅改善一般 LP 几何的普通割”；
2. 对于同时包含 `4x1` 槽位变量、`2x2` 序列变量、时间变量和完工变量的大规模实例，默认割排序容易把计算资源消耗在对最终调度瓶颈帮助较小的割上，导致求解时间长、节点数多；
3. 缺少针对双源混流 PEC 边界逻辑和共享旋转腔耦合结构的定制化割筛选机制，难以稳定提升根节点和后续节点的收敛效率。

## 1.3 与本发明相关的现有技术二

### 1.3.1 现有技术二的技术方案

现有技术二主要是面向通用 MILP 的 Learning to Cut 或层次化割选择方法，例如在求解器分离阶段提取候选割特征，再通过神经网络或强化学习对候选割进行打分、排序或保留比例决策。其典型方案包括：

1. 使用目标平行度、割有效性、支持度、整数支持度等通用几何特征表示候选割；
2. 采用高层网络确定保留比例，低层序列网络输出候选割的选择顺序；
3. 在训练阶段用策略梯度、演员-评论家或 REINFORCE 方式更新网络参数；
4. 在测试阶段通常采用单一路径贪心解码，直接给出候选割序列并反馈给求解器。

该类方法在通用 MILP 上已经表现出一定加速效果，但其核心特征与决策结构通常并不针对双源混流旋转腔调度模型的物理变量族设计。

### 1.3.2 现有技术二的缺点

与本发明相比，现有技术二至少存在以下缺点：

1. 通用割特征缺乏对双源混流旋转腔模型变量语义的刻画，无法反映某条割主要作用于 `4x1` 分配、`2x2` 流水位置、时间连续性还是完工时间变量；
2. 高低层策略虽然可以决定保留比例和割序列，但若没有 family-aware 的修复与重排机制，容易出现选出的割过度集中在某一类变量族上的问题，导致关键结构覆盖不足；
3. 测试阶段若采用单路径贪心解码，低层策略早期一步的误判会被持续放大，导致割序列稳定性不足；
4. 现有方法大多面向一般 MILP，没有将双源混流、共享旋转腔、PEC 边界逻辑与学习式割选择紧密结合起来。

# 2 本发明技术方案的详细阐述（发明内容）

## 2.1 本发明所要解决的技术问题（发明目的）

本发明的目的是针对双源混流旋转腔组合设备调度问题，提出一种“精确建模 + 结构感知学习式加速 + 束搜索稳健解码”相结合的求解方法，在保证工艺约束严格可行的基础上，提高大规模调度 MIP 的求解效率与解质量。具体要解决的技术问题包括：

1. 如何建立能够统一描述共享旋转腔 `CH2/CH3`、固定 `4x1/2x2` 模式需求、PEC 补位与首尾边界逻辑、时间连续性以及完工目标的精确 MIP；
2. 如何在分支定界过程中，从大量候选割中识别出真正有助于收紧“双源混流 + 旋转腔”结构瓶颈的候选割；
3. 如何将 A3C 风格的分层 actor-critic 强化学习与束搜索结合起来，在不直接替代精确求解器的情况下，提高割选择策略的稳定性、泛化性和最终调度求解效果。

## 2.2 本发明提供的完整技术方案（发明方案）

### 2.2.1 步骤一：建立双源混流旋转腔组合设备的精确 MIP 模型

本发明首先建立面向双源混流旋转腔组合设备的精确 MIP 模型。设：

1. `M = {CH2, CH3}` 表示共享旋转腔集合；
2. `J^F` 表示固定要求采用 `4x1` 模式的产品对集合；
3. `J^M` 表示固定要求采用 `2x2` 模式的产品对集合；
4. `F = {1, 2, ..., F_max}` 表示每个腔体上的 `4x1` 槽位集合；
5. `R = {1, 2, ..., R_max}` 表示每个腔体上的 `2x2` 产品对位置集合；
6. `C = {1, 2, ..., R_max + 1}` 表示 `2x2` 周期集合；
7. 每个产品对包含 2 片产品晶圆，每个 PEC 对包含 2 片 PEC wafer。

定义如下决策变量：

1. `x_{jmf} in {0,1}`：产品对 `j` 是否被分配到腔体 `m` 的 `4x1` 槽位 `f`；
2. `u_{mf} in {0,1}`：腔体 `m` 的 `4x1` 槽位 `f` 是否被启用；
3. `p_{mf} in {0,1}`：槽位 `(m,f)` 是否使用一个 PEC 对进行补位；
4. `z_{mf} in {0,1}`：槽位 `(m,f)` 是否位于同腔 `2x2` 连续块之后；
5. `y_{jmr} in {0,1}`：产品对 `j` 是否被分配到腔体 `m` 的 `2x2` 位置 `r`；
6. `v_{mr} in {0,1}`：腔体 `m` 的 `2x2` 位置 `r` 是否被启用；
7. `q_{mc} in {0,1}`：腔体 `m` 的 `2x2` 周期 `c` 是否存在；
8. `a_m in {0,1}`：腔体 `m` 是否存在 `2x2` 连续加工块；
9. `l_{mc} in {0,1}`：周期 `c` 是否是腔体 `m` 的最后一个 `2x2` 周期；
10. `t^{F,s}_{mf}, t^{F,e}_{mf}`：`4x1` 槽位开始与结束时间；
11. `t^{M,s}_{mc}, t^{M,e}_{mc}`：`2x2` 周期开始与结束时间；
12. `B^e_m`：腔体 `m` 上 `2x2` 连续块的结束时间；
13. `C_j`：产品对 `j` 的完工时间；
14. `C_max`：系统最大完工时间。

项目代码采用如下持续时间定义：

1. `T_F = full_process_time + 2 * pair_transfer_time`；
2. `T_B = mix_boundary_process_time + 2 * pair_transfer_time`；
3. `T_I = mix_internal_process_time + 2 * pair_transfer_time`；
4. `Delta = pm_transfer_gap`。

其中 `T_F` 表示 `4x1` 批次周期时长，`T_B` 表示 `2x2` 首尾边界周期时长，`T_I` 表示 `2x2` 内部交叠周期时长。

优选地，MIP 的关键约束包括：

（1）模式固定下的唯一分配约束：

`sum_{m in M} sum_{f in F} x_{jmf} = 1,  for all j in J^F`

`sum_{m in M} sum_{r in R} y_{jmr} = 1,  for all j in J^M`

上述约束表示：每个产品对的工艺模式由输入参数预先确定，不在模型中再作为路由决策变量。

（2）`4x1` 槽位容量与 PEC 补位约束：

`sum_{j in J^F} x_{jmf} + p_{mf} = 2 * u_{mf}`

`u_{mf} <= sum_{j in J^F} x_{jmf}`

`u_{mf} >= u_{m,f+1}`

第一式表示每个启用的 `4x1` 槽位恰好容纳两个“对单元”，该单元可以是两个产品对，也可以是“一个产品对 + 一个 PEC 对”；第二式禁止纯 PEC 空批；第三式保证启用槽位形成前缀。

（3）`2x2` 位置前缀与周期诱导约束：

`v_{mr} = sum_{j in J^M} y_{jmr}`

`v_{mr} >= v_{m,r+1}`

`a_m = v_{m1}`

`q_{m1} = v_{m1}`

对内部周期 `c = 2, ..., R_max`，有：

`q_{mc} >= v_{m,c-1}`

`q_{mc} >= v_{mc}`

`q_{mc} <= v_{m,c-1} + v_{mc}`

并且：

`q_{m,R_max+1} = v_{m,R_max}`

`q_{mc} >= q_{m,c+1}`

这组约束确保 `2x2` 产品对在同一腔体上形成有序前缀序列，并自动推导出首周期、内部周期与尾周期。

（4）最后周期识别约束：

`a_m = sum_{c in C} l_{mc}`

`l_{mc} <= q_{mc}`

`l_{mc} + q_{m,c+1} <= 1`

`l_{mc} >= q_{mc} - q_{m,c+1}`

该组约束用于唯一标识 `2x2` 连续块的最后一个周期，以便定义连续块结束时间 `B^e_m`。

（5）全局 PEC 预算约束：

`sum_{m in M} sum_{f in F} p_{mf} + 2 * sum_{m in M} a_m <= N_PEC`

其中 `N_PEC` 为可用 PEC 对总数。该式反映出：每个 `4x1` 不足槽位消耗 1 个 PEC 对，而每个激活的 `2x2` 连续块固定消耗 2 个 PEC 对，分别用于首尾边界。

（6）时间连续性约束：

`t^{F,e}_{mf} = t^{F,s}_{mf} + T_F * u_{mf}`

`t^{F,s}_{m,f+1} >= t^{F,e}_{mf} + Delta - BigM * (2 - u_{mf} - u_{m,f+1})`

当 `c` 为首周期或尾周期时：

`t^{M,e}_{mc} = t^{M,s}_{mc} + T_B * q_{mc}`

当 `c` 为内部周期时：

`t^{M,e}_{mc} = t^{M,s}_{mc} + T_B * q_{mc} + (T_I - T_B) * v_{mc}`

并满足：

`t^{M,s}_{m,c+1} >= t^{M,e}_{mc} + Delta - BigM * (1 - q_{m,c+1})`

`t^{M,s}_{m,c+1} <= t^{M,e}_{mc} + Delta + BigM * (2 - q_{mc} - q_{m,c+1})`

（7）同腔两种模式互斥约束：

`t^{F,e}_{mf} <= t^{M,s}_{m1} - Delta + BigM * z_{mf} + BigM * (1 - u_{mf}) + BigM * (1 - a_m)`

`t^{F,s}_{mf} >= B^e_m + Delta - BigM * (1 - z_{mf}) - BigM * (1 - u_{mf}) - BigM * (1 - a_m)`

上述约束表示：同一旋转腔上 `2x2` 连续块视为一个整体时间块，`4x1` 槽位只能整体位于该块之前或之后，不能与之重叠。

（8）完工时间与目标函数：

若 `x_{jmf} = 1`，则：

`C_j = t^{F,e}_{mf}`

若 `y_{jmr} = 1`，则：

`C_j = t^{M,e}_{m,r+1}`

并满足：

`C_max >= C_j, for all j`

目标函数为：

`min C_max`

通过上述建模，本发明能够精确表达共享旋转腔 `CH2/CH3`、`4x1` 与 `2x2` 模式、PEC 补位与边界、加工时间连续性以及最终完工目标，为后续学习式求解加速提供严格且可解释的优化基础。

### 2.2.2 步骤二：构造面向双源混流旋转腔 MIP 的结构感知候选割特征

在求解器分离阶段，设当前节点产生的候选割集合为 `G_t = {g_1, g_2, ..., g_{N_t}}`。本发明不直接使用通用 MILP 割特征，而是构造“通用几何特征 + 结构语义特征”的联合表示。

对第 `i` 条候选割，定义 13 维通用几何特征向量：

`phi_i^gen = [obj_parallelism_i, efficacy_i, support_i, integral_support_i, violation_i, mean_cut_i, max_cut_i, min_cut_i, std_cut_i, mean_obj, max_obj, min_obj, std_obj]`

其中：

1. `obj_parallelism_i` 表示割与目标函数的平行程度；
2. `efficacy_i` 表示割的有效性；
3. `support_i` 表示该割非零系数占全部变量的比例；
4. `integral_support_i` 表示该割在整数变量上的支持比例；
5. `violation_i` 表示当前 LP 解对该割的归一化违反程度；
6. 其余分量分别表示割系数与目标系数的统计量。

进一步地，设旋转腔调度 MIP 的变量族集合为：

`F_var = {route, full_assign, mix_assign, timing, completion, other}`

其中：

1. `route` 表示路由及历史兼容变量族；
2. `full_assign` 表示 `4x1` 槽位分配及 PEC 补位变量族；
3. `mix_assign` 表示 `2x2` 位置、周期激活与最后周期变量族；
4. `timing` 表示开始、结束、连续块结束等时间变量族；
5. `completion` 表示产品对完工时间与 `C_max` 变量族；
6. `other` 表示上述之外的辅助变量。

对于第 `i` 条候选割，记其系数向量为 `a_i = (a_{i1}, ..., a_{in})`，则第 `f` 个变量族上的系数质量占比定义为：

`r_{if} = (sum_{k in V_f intersect supp(g_i)} |a_{ik}|) / (sum_{k in supp(g_i)} |a_{ik}| + eps)`

其中 `V_f` 表示变量族 `f` 对应的变量集合，`supp(g_i)` 表示候选割 `g_i` 的非零系数支撑集。

此外，定义：

`r_i^bin = (sum_{k in V_bin intersect supp(g_i)} |a_{ik}|) / (sum_{k in supp(g_i)} |a_{ik}| + eps)`

`r_i^cont = (sum_{k in V_cont intersect supp(g_i)} |a_{ik}|) / (sum_{k in supp(g_i)} |a_{ik}| + eps)`

`d_i = max_{f in F_var \\ {other}} r_{if}`

`rho_i = 1 - r_{i,other}`

`H_i = - (1 / log |F_var|) * sum_{f in F_var} r_{if} * log(r_{if} + eps)`

其中：

1. `r_i^bin` 和 `r_i^cont` 分别表示该割在二进制变量和连续变量上的占比；
2. `d_i` 表示主导变量族占比；
3. `rho_i` 表示结构化变量参与度；
4. `H_i` 表示变量族分布熵，用于衡量该割覆盖结构的分散程度。

因此，第 `i` 条候选割的最终结构感知特征向量定义为：

`phi_i = [phi_i^gen, r_{i,route}, r_{i,full_assign}, r_{i,mix_assign}, r_{i,timing}, r_{i,completion}, r_{i,other}, r_i^bin, r_i^cont, d_i, H_i]`

优选地，上述联合特征为 23 维向量，对应项目代码中的结构感知高级割特征表示。通过该表示，策略网络不再只知道“割的几何强度”，还能够知道“该割主要收紧的是共享腔分配结构、`2x2` 流水结构，还是时间与完工结构”。

### 2.2.3 步骤三：构建结构感知分层 A3C 风格强化学习策略

设当前分离节点的候选割特征矩阵为：

`X_t = [phi_1, phi_2, ..., phi_{N_t}]^T in R^{N_t x d}`

其中 `d = 23`。

为了同时利用通用几何特征与结构语义特征，本发明先通过结构感知输入适配器对 `X_t` 进行变换。记 `X_t^g` 为通用几何部分，`X_t^s` 为结构语义部分，则：

`X'_t = LayerNorm(X_t)`

`Z_t^g = tanh(W_g X_t^g + b_g)`

`Z_t^s = tanh(W_s X_t^s + b_s)`

`Gamma_t = sigmoid(W_a X'_t + b_a)`

`X''_t = Gamma_t odot [Z_t^g ; Z_t^s] + (1 - Gamma_t) odot X'_t`

上述门控融合使网络能够自适应权衡“通用割几何强度”和“问题结构语义”。

在此基础上，本发明采用高层比例策略与低层序列策略相结合的分层 A3C 风格 actor-critic 框架。

1. 高层 actor 负责决定当前节点应保留多少比例的候选割；
2. 低层 actor 负责决定具体保留哪些割以及它们的排序；
3. critic 负责给出当前候选割状态的价值估计。

（1）高层比例策略

高层策略网络输出一个高斯分布的均值和对数标准差：

`(mu_t, log_sigma_t) = f_H(X''_t)`

采样得到预压缩动作：

`tilde_p_t = mu_t + sigma_t * epsilon_t,   epsilon_t ~ N(0, 1)`

再通过 `tanh` 映射到 `[-1, 1]`，并线性变换到 `[0, 1]`：

`p_t = (tanh(tilde_p_t) + 1) / 2`

最终得到本轮割保留数：

`K_t = max{2, min(floor(p_t * N_t), K_t^max)}`

其中 `K_t^max` 为求解器允许的最大保留割数。该设计对应代码中的 `CutsPercentPolicy`。

（2）低层序列策略

低层策略采用指针网络（Pointer Network）对候选割进行有序选择，输出序列概率：

`pi_L(a_t | X''_t) = prod_{ell=1}^{L_t} pi_L(a_{t,ell} | X''_t, a_{t,<ell})`

其中 `a_t = (a_{t,1}, ..., a_{t,L_t})` 表示当前节点的割序列。

为避免重复选择，低层解码时对已选索引施加掩码：

`pi_L(a_{t,ell} = i | .) = exp(z_{t,ell,i} + m_{t,ell,i}) / sum_j exp(z_{t,ell,j} + m_{t,ell,j})`

其中：

`m_{t,ell,i} = -inf,   if i in a_{t,<ell}`

`m_{t,ell,i} = 0,      otherwise`

优选地，低层网络还可增加结束标记 `EOS`，使策略能够在最大解码长度之前提前结束输出。

（3）critic 价值函数

critic 网络对当前候选割状态给出标量价值估计：

`V_t = V_psi(X''_t)`

该值用于构造优势函数，降低策略梯度估计方差。

（4）A3C 风格并行训练

本发明优选采用多进程并行采样、主进程聚合更新的 A3C 风格训练方式。设并行工作进程集合为 `W = {1, 2, ..., W_num}`，第 `w` 个工作进程在求解环境中生成轨迹 `tau^(w)`，主进程将所有轨迹汇总后执行策略和价值网络更新：

`grad Theta = sum_{w in W} grad Theta(tau^(w))`

对于低层 actor，定义回报 `R_t` 为求解器性能指标的负值，优选地可以取：

`R_t = - (lambda_1 * T_solve + lambda_2 * N_nodes + lambda_3 * PDI + lambda_4 * Gap)`

其中：

1. `T_solve` 为求解时间；
2. `N_nodes` 为搜索节点数；
3. `PDI` 为 primal-dual integral；
4. `Gap` 为原始对偶间隙。

在优选实施方式中，可取 `lambda_1 = 1`，其余系数为 0，即直接以求解时间的负值作为回报。

优势函数定义为：

`A_t = R_t - V_psi(X''_t)`

低层 actor 的损失函数定义为：

`L_low = - E[ A_t * log pi_L(a_t | X''_t) ]`

critic 的损失函数定义为：

`L_critic = E[ (V_psi(X''_t) - R_t)^2 ]`

对于高层 actor，优选使用指数滑动平均基线：

`b_t = beta * b_{t-1} + (1 - beta) * R_t`

其损失函数定义为：

`L_high = - E[ (R_t - b_t) * log pi_H(p_t | X''_t) ]`

由此实现高层“割数量决策”和低层“割顺序决策”的协同学习。

### 2.2.4 步骤四：对低层输出执行 family-aware 修复与重排

仅依靠低层策略输出的原始割序列，容易出现“过度偏向某一变量族”的问题。例如某一轮策略可能集中选出大量时间变量相关割，而忽略了共享腔分配或 `2x2` 周期结构相关割。为此，本发明设计 family-aware 修复与重排机制，对低层输出进行结构化后处理。

首先，针对每条候选割计算结构评分。记：

1. `tilde_e_i` 为 `efficacy` 的最小-最大归一化值；
2. `tilde_v_i` 为 `violation` 的最小-最大归一化值；
3. `tilde_u_i` 为 `integral_support` 的最小-最大归一化值。

则基础结构评分可定义为：

`s_i = 0.36 * tilde_e_i + 0.24 * tilde_v_i + 0.15 * tilde_u_i + 0.15 * rho_i + 0.10 * d_i - 0.05 * H_i`

然后，在候选排序前窗 `Omega_t` 上统计各变量族的权重质量：

`w_f = sum_{i in Omega_t} r_{if}`

根据比例构造变量族配额：

`q_f = RoundQuota( K_t * w_f / sum_g w_g )`

其中 `RoundQuota(.)` 表示带残差补偿的配额离散化过程，保证总配额不超过 `K_t`，同时尽量保留占比较高变量族的代表性割。

进一步地，对已选割集合 `S` 中待补充候选 `i` 定义多样性惩罚后的综合得分：

`sim(i, j) = <xi_i, xi_j> / (||xi_i||_2 * ||xi_j||_2 + eps)`

`Score(i | S) = s_i - lambda * max_{j in S} sim(i, j) - gamma * Overflow(i)`

其中：

1. `xi_i` 为由前 5 个几何特征和变量族占比拼接得到的相似性向量；
2. `Overflow(i)` 表示当前候选所属变量族是否已经超过配额；
3. `lambda` 和 `gamma` 分别为相似性惩罚系数和配额越界惩罚系数。

该机制优先保证关键变量族的覆盖，再用多样性约束抑制高度相似的重复割，最终输出更加稳定、结构覆盖更充分的目标割序列。

### 2.2.5 步骤五：在推理阶段引入束搜索获得更优割序列

训练完成后，本发明在测试或在线求解阶段不再局限于单一路径贪心解码，而是在低层指针网络上引入束搜索（beam search）以提高割序列质量和稳定性。

设束宽为 `K_beam`，优选可取 `K_beam = 3`。定义第 `ell` 步部分序列 `a_{1:ell}` 的路径得分为：

`Gamma(a_{1:ell}) = sum_{u=1}^{ell} log pi_L(a_u | X''_t, a_{<u})`

束搜索过程如下：

1. 初始化 `B_0 = {emptyset}`；
2. 对于每个部分序列 `a in B_ell`，根据低层策略概率扩展多个新候选；
3. 对所有扩展后的部分序列按 `Gamma(.)` 排序，仅保留前 `K_beam` 个序列；
4. 当输出结束标记 `EOS` 或达到最大解码长度后，取得分最高的完整序列作为低层输出。

形式化地，可写为：

`B_{ell+1} = TopK_{K_beam}( union_{a in B_ell} Expand(a) )`

`a_t^* = argmax_{a in B_L} Gamma(a)`

得到 `a_t^*` 后，再执行前述 family-aware 修复与重排，最终获得当前节点的结构感知目标割序列。

与贪心解码相比，束搜索保留了多条高概率候选路径，能够有效减轻早期单步决策失误对整条割序列的放大效应，特别适用于双源混流旋转腔调度 MIP 中候选割数量多、变量结构复杂的场景。

### 2.2.6 步骤六：将目标割序列反馈给求解器并输出最终调度解

在 branch-and-cut 的每一轮分离阶段，本发明按照如下流程执行：

1. 由求解器产生候选割集合 `G_t`；
2. 提取每条候选割的 23 维结构感知特征；
3. 由高层 actor 给出当前保留比例 `p_t` 和保留数量 `K_t`；
4. 由低层 actor 通过指针网络生成候选割序列；
5. 在推理阶段可结合束搜索产生多条高概率候选路径；
6. 对低层输出执行 family-aware 修复与重排；
7. 将最终选中的前 `K_t` 条割优先反馈给求解器，继续执行分支定界。

本发明的神经网络并不直接输出最终调度方案，而是作为精确求解器内部的结构感知割选择器，对求解过程进行加速和引导。最终的调度结果仍由精确求解器给出，因此在满足工艺可行性的前提下，能够同时获得：

1. 求解状态；
2. 最优或当前最优目标值 `C_max`；
3. 非零变量取值；
4. 求解时间、节点数、间隙等统计信息。

因此，本发明属于“学习增强的精确调度求解方法”，不是脱离物理约束的纯启发式近似算法。

## 2.3 本发明技术方案带来的有益效果

与现有技术相比，本发明至少具有以下有益效果：

1. 能够精确描述双源混流旋转腔设备的核心工艺逻辑。通过共享腔 `CH2/CH3`、`4x1/2x2` 模式、PEC 补位和边界、时间连续性以及完工目标的一体化 MIP 建模，实现了对复杂调度规则的统一表达；
2. 能够把求解器分离阶段的候选割与设备物理结构建立一一对应关系。通过结构感知变量族特征，策略网络可以识别割作用于共享腔分配、`2x2` 周期激活、时间连续性还是完工瓶颈，从而比通用割特征更适合本问题；
3. 通过高层保留比例决策和低层割序列决策相结合的 A3C 风格分层 actor-critic 框架，实现了“选多少割”和“按什么顺序选割”的联合优化，提高了策略表达能力；
4. 通过 family-aware 修复与重排机制，在保持学习策略主导作用的同时增强了不同变量族的覆盖度，减少了割选择结果过度集中的问题；
5. 通过将束搜索引入推理阶段，显著提升了低层解码稳定性，减小单一路径贪心选择带来的波动，提高了复杂实例上的求解鲁棒性；
6. 由于最终调度解仍由精确求解器输出，因此本发明在保持严格工艺可行性的基础上，实现了对大规模双源混流旋转腔调度 MIP 的学习式加速。

# 3 针对2中的技术方案，是否还有别的替代方案同样能完成发明目的

在不背离本发明核心思想的前提下，还可以采用如下替代方案：

1. 求解器替代：可将 SCIP 替换为 Gurobi、CPLEX 或其他支持分支定界与割平面的 MIP 求解器，只要仍然在分离阶段接入学习式割选择模块，均属于本发明的等同方案；
2. 低层序列模型替代：可将指针网络替换为带掩码的 Transformer 解码器、带注意力的循环网络或其他能够输出无重复候选割序列的网络结构；
3. 高层比例策略替代：可将高斯策略替换为 Beta 分布策略、离散档位策略或其他连续动作策略，只要能够输出候选割保留比例即可；
4. 强化学习算法替代：除 A3C 风格算法外，也可采用 PPO、SAC、REINFORCE 等策略优化方法，只要仍然保持高层比例决策、低层序列决策和价值基线机制，即属于本发明的等效实现；
5. 搜索算法替代：束搜索可替换为 best-first search、MCTS 或其他多路径保留式序列搜索方法，只要仍然通过多候选路径降低单步解码误差即可；
6. 结构感知特征替代：变量族划分、结构参与比例、主导变量族占比、结构熵等特征可以根据设备结构进一步扩展，只要仍然体现候选割与双源混流旋转腔调度变量语义之间的对应关系，均属于本发明保护范围内的合理变形。

# 4 本发明的技术关键点和欲保护点是什么

为便于专利代理人撰写权利要求书，本发明的关键技术点和欲保护点至少包括：

1. 一种面向双源混流旋转腔组合设备的精确 MIP 建模方法，其核心在于把共享旋转腔 `CH2/CH3`、固定 `4x1/2x2` 模式、PEC 补位与边界、时间连续性和 `C_max` 目标统一纳入同一约束体系；
2. 一种针对旋转腔调度 MIP 候选割的结构感知特征构造方法，其核心在于将候选割在 `route/full_assign/mix_assign/timing/completion/other` 变量族上的系数占比、结构参与度和结构熵显式编码为学习状态；
3. 一种“高层决定候选割保留比例、低层决定候选割序列”的分层 A3C 风格 actor-critic 求解框架；
4. 一种将高层连续比例动作通过 `p_t = (tanh(tilde_p_t) + 1) / 2` 映射为割保留比例、再转换为具体保留数量 `K_t` 的方法；
5. 一种基于变量族配额与多样性约束的 family-aware 割修复与重排机制，其核心在于通过结构评分、配额约束和相似性惩罚生成更符合双源混流旋转腔结构瓶颈的割集合；
6. 一种将束搜索嵌入低层序列解码的学习式割选择方法，其核心在于以路径累计对数概率为评分保留多条高概率路径，再输出得分最高的割序列；
7. 一种“学习式割选择 + 精确求解器反馈”的闭环求解方案，即神经网络负责提升割选择质量，最终调度解仍由精确 branch-and-cut 求解器输出。
